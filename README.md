# Kronos-X

## Automated Experimental Laboratory — Architectural Baseline v1

Kronos-X is a new experimental system for exact-source execution, evidence generation, reconciliation, reproducibility, adversarial evaluation, repair traceability, and qualification review.

Kronos-X is not a rewrite or replacement of historical Kronos Build & Evidence Lab. Historical Kronos remains a separate historical artifact.

### Mission
Turn an exact engineering state into independently traceable experimental evidence without allowing evidence, qualification, consensus, or system output to become authority.

### System-of-systems lineage
Original system-of-systems → KCN / MANIFEX / KSI → evolutionary architecture → EA-G1 → EA-G2 → Kronos-X

This lineage is architectural history, not a claim that every later mechanism existed in every earlier implementation.
