# Kronos-X Invariants

| ID | Invariant | Meaning |
|---|---|---|
| KX-I01 | Historical immutability | Historical evidence may be referenced and compared, never rewritten. |
| KX-I02 | Exact source identity | Every execution is tied to an exact source state. |
| KX-I03 | Isolated execution | Execution cannot escape its defined worker boundary. |
| KX-I04 | Complete provenance | Significant actions are attributable to a run/execution record. |
| KX-I05 | Continuous lineage | Indexing occurs before, during, and after experimentation. |
| KX-I06 | Repair traceability | Automated changes have an originating finding and repair identity. |
| KX-I07 | Independent review | A repair cannot establish its own correctness merely by passing its own tests. |
| KX-I08 | Reproducibility | Important conclusions can be rerun and compared. |
| KX-I09 | Evidence/qualification separation | Evidence does not automatically become qualification. |
| KX-I10 | No self-authority | Kronos-X cannot grant authority, qualification, ratification, or sovereignty to itself. |
| KX-I11 | No silent completion | Unperformed stages become NOT_MEASURED, BLOCKED, INCONCLUSIVE, etc.; never fabricated PASS. |
