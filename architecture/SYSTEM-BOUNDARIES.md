# System Boundaries

Human authority is outside Kronos-X.

KSI defines the epistemic and governance boundary. It does not become authoritative merely by operating inside the architecture.

KCN provides cognitive/intelligence capabilities when explicitly integrated.

MANIFEX provides engineering/execution/infrastructure capabilities when explicitly integrated.

The Index Machine remains independently usable and maintains source/history lineage.

Kronos-X orchestrates experimental execution and evaluation.

Reconciliation compares independently produced lineage and execution records. It does not silently repair disagreement.

Evidence records observations and relationships. Evidence does not grant authority.

Qualification is a separate review state and is never implied by workflow completion.
