# Kronos-X Architectural Baseline v1

Kronos-X is a new system, not a larger Kronos v1.

Its primary responsibility is experimental execution and evaluation. It cooperates with, but does not subsume, the Index Machine, evidence store, KSI governance boundary, KCN, or MANIFEX.

| Component | Primary question |
|---|---|
| Index Machine | What exists, changed, and relates to history? |
| Kronos-X | What happens when this exact state is executed/evaluated? |
| Reconciliation | Do lineage and execution records agree? |
| Evidence Store | Can observations/relationships be independently verified? |
| KSI | What does evidence permit us to conclude? |
| Human | What is ultimately authorized/accepted? |

Laboratory loop: DISCOVER → INDEX → PIN → ISOLATE → BUILD → BASELINE → TEST → BENCHMARK → EVALUATE → DIAGNOSE → REPAIR → RE-INDEX → RETEST → INDEPENDENT REVIEW → FULL E2E → REPRODUCE → RECONCILE → SEAL EVIDENCE → REPORT.
